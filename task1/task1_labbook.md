# Task 1: Sine Wave Generator with Frequency Control

## Overview

This task implements a sine wave generator using a Read-Only Memory (ROM) to store sine values and a counter to control the frequency. The system uses incremental addressing to step through the ROM table, with frequency scaling applied via multiplication.

## Files Included

### 1. Sine Wave Generator Module (`singen.sv`)

```verilog
module singen (
    input logic [7:0] incr,
    input logic [7:0] freq,
    input logic rst, en, clk,
    output logic [7:0] dout
);

    logic [7:0] addr;
    counter counter (.clk(clk), .rst(rst), .ld(en), .v(incr), .count(addr));

    logic [7:0] adj_addr;
    logic [7:0] cur_freq;

always_ff @(posedge clk) begin
    if (rst) 
        cur_freq <= 8'd1;     // Set a default frequency on reset
    else if (en) 
        cur_freq <= freq;     // Lock in the new frequency when 'en' is high
end
assign adj_addr = addr * cur_freq;
rom sinevals (.clk(clk), .addr(adj_addr), .dout(dout));
endmodule

```

### 2. ROM Module (`rom.sv`)

```verilog
module rom #(
    parameter ADDRESS_WIDTH = 8, 
              DATA_WIDTH = 8
)(
    input logic clk,
    input logic [ADDRESS_WIDTH - 1:0] addr,
    output logic [DATA_WIDTH - 1: 0] dout
);
    logic [DATA_WIDTH - 1: 0] rom_array [2**ADDRESS_WIDTH -1 : 0];

    initial begin
        $display("Loading rom.");
        $readmemh("sinerom.mem", rom_array);
    end;

always_ff @(posedge clk) begin
    dout <= rom_array[addr];
end
endmodule

```

### 3. Counter Module (`counter.sv`)

```verilog
module counter #(
  parameter WIDTH = 8
)(
  // interface signals
  input  logic             clk,      // clock
  input  logic             rst,      // reset
  input  logic             ld,       // load counter from data
  input  logic [WIDTH-1:0] v,        // value to preload
  output logic [WIDTH-1:0] count     // count output
);

always_ff @ (posedge clk)
  if (rst) count <= {WIDTH{1'b0}};
  else     count <= ld ? v : count + {{WIDTH-1{1'b0}},1'b1};
endmodule

```

### 5. ROM Generation Script (`sinegen.py`)

```python
import math
import string
f = open("sinerom.mem","w")
for i in range(256):
    v = int(math.cos(2*3.1416*i/256)*127+127)
    if (i+1)%16 == 0:
        s = "{hex:2X}\n"
    else:
        s = "{hex:2X} "
    f.write(s.format(hex=v))

f.close()
```

## Frequency Adjustment Mechanism

### How singen Adjusts Frequency

The frequency of the generated sine wave is controlled through a combination of counter reset and frequency scaling:

1. **Counter Reset**: When `rst` is asserted, the counter (`count`) returns to 0.

2. **Frequency Loading**: The `en` signal enables loading of new values into both the counter (via `incr`) and the frequency multiplier (via `freq`).

3. **Address Scaling**: The ROM address is scaled by the frequency multiplier:
   - `adj_addr = addr * cur_freq`
   - Higher frequency values cause faster progression through the ROM table

4. **Frequency Control**: The frequency is determined by:
   - Clock period (fixed by system clock)
   - ROM size (256 points)
   - Frequency multiplier (`cur_freq`)
   - Counter increment value (`incr`)

5. **To Change Frequency**:
   - Assert `en` to latch the new frequency value from `freq` input
   - The sine wave will traverse through the ROM table at a rate determined by `addr * freq`
   - Higher frequencies complete cycles faster by skipping more ROM points per clock

**Key Point**: The frequency multiplier allows dynamic adjustment of the sine wave speed without changing the counter increment pattern. Resetting enables starting from a known phase with the current frequency setting.
