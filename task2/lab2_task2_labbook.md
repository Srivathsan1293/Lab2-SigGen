# Task 2: Sine and Cosine Dual Wave Generation

## Overview

This task extends the sine wave generator from Task 1 to generate TWO simultaneous sinusoidal signals with different phases. The phase offset between the two sinusoids is controlled by a rotary encoder on Vbuddy using the `off` parameter. The implementation uses a dual-port ROM where both ports read from the same memory array but at different addresses.

## Files Included

### 1. Dual-Port ROM Module (`rom.sv`)

```verilog
module rom #(
    parameter ADDRESS_WIDTH = 8, 
              DATA_WIDTH = 8
)(
    input logic clk,
    input logic [ADDRESS_WIDTH - 1:0] addr1,
    input logic [ADDRESS_WIDTH - 1:0] addr2,
    output logic [DATA_WIDTH - 1: 0] dout1,
    output logic [DATA_WIDTH - 1: 0] dout2
);
    logic [DATA_WIDTH - 1: 0] rom_array [2**ADDRESS_WIDTH -1 : 0];

    initial begin
        $display("Loading rom.");
        $readmemh("sinerom.mem", rom_array);
    end;

    always_ff @(posedge clk) begin
        dout1 <= rom_array[addr1];
        dout2 <= rom_array[addr2];
    end
endmodule
```

### 2. Counter Module (`counter.sv`)

```verilog
module counter #(
  parameter WIDTH = 8
)(
  // interface signals
  input  logic             clk,      // clock
  input  logic             rst,      // reset
  input  logic             ld,       // load counter from data
  input  logic [WIDTH-1:0] v,        // value to preload
  output logic [WIDTH-1:0] count     // count output
);

always_ff @ (posedge clk)
  if (rst) count <= {WIDTH{1'b0}};
  else     count <= ld ? v : count + {{WIDTH-1{1'b0}},1'b1};
endmodule
```

### 3. Sine/Cosine Generator Module (`singen.sv`)

```verilog
module singen (
    input logic [7:0] incr,
    input logic [7:0] off,
    input logic rst, en, clk,
    output logic [7:0] dout1,
    output logic [7:0] dout2
);

    logic [7:0] addr;
    counter counter (.clk(clk), .rst(rst), .ld(en), .v(incr), .count(addr));

    rom sinevals (.clk(clk), .addr1(4*addr), .dout1(dout1), .addr2(4*(addr+off)), .dout2(dout2));
endmodule
```

### 5. ROM Generation Script (`sinegen.py`)

```python
import math
import string
f = open("sinerom.mem","w")
for i in range(256):
    v = int(math.cos(2*3.1416*i/256)*127+127)
    if (i+1)%16 == 0:
        s = "{hex:2X}\n"
    else:
        s = "{hex:2X} "
    f.write(s.format(hex=v))

f.close()
```

## Phase Offset Mechanism

### How Dual Wave Generation Works

The dual sine/cosine generator uses a single 256-point ROM but reads from it at two different addresses:

1. **First Output (sinewave)**: Address = `4 * addr`
   - Reads directly from the ROM starting at address proportional to counter value

2. **Second Output (cosinewave)**: Address = `4 * (addr + off)`
   - Same base addressing but with an offset added
   - The offset controls the phase difference between the two signals

### Phase Offset Control

The phase difference is determined by the offset value passed to Vbuddy via `vbdValue()`:

- **Default offset (0x64 = 100 decimal)**: Provides approximately 90° phase shift
- **Offset = 64**: Creates exactly 90° phase shift between outputs
- **Quadrature signals**: When offset = 64, dout1 becomes a pure sine wave and dout2 becomes a pure cosine wave at the same frequency

### Why the Offset is Multiplied by 4

The ROM addressing uses `4*addr` and `4*(addr+off)` to:
- Access every 4th entry in the 256-point table (effectively creating a 64-point "virtual" ROM)
- Maintain proper scaling for the phase offset calculation
- Allow smaller offset values to produce meaningful phase shifts

## Frequency Adjustment Mechanism

### How singen Adjusts Frequency

The frequency of both generated sine/cosine waves is controlled through counter reset and increment:

1. **Counter Reset**: When `rst` is asserted, the counter (`count`) returns to 0
2. **Frequency Loading**: The `en` signal enables loading new values from `incr` input
3. **Address Generation**: ROM addresses are calculated as multiples of the counter value
4. **Frequency Control**: The sine wave speed is determined by:
   - Clock period (fixed by system clock)
   - Counter increment value (`incr`) obtained from `vbdValue()`
   - ROM size and addressing scale factor

### To Change Frequency:
- Use `en` signal to latch new increment value from `incr` input
- Both outputs will change frequency together since they share the same counter
- Resetting allows starting from a known phase with current frequency setting
